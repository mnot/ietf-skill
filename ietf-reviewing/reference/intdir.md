# intdir — Internet Area Directorate

One boilerplate paragraph, then the review. No mandated headings.

## Form

```
I am an assigned INT directorate reviewer for draft-example-thing. These
comments were written primarily for the benefit of the Internet Area
Directors. Document editors and shepherd(s) should treat these comments just
like they would treat comments from any other IETF contributors and resolve
them along with any other Last Call comments that have been received. For more
details on the INT Directorate, see
https://datatracker.ietf.org/group/intdir/about/

<Thanks, plus a one-clause characterisation of the document.>

<The verdict.>

<Comments, commonly as a short list with the draft quoted before each.>
```

## Notes

**The boilerplate names the draft**, unlike tsvart's, so it is not quite boilerplate —
substitute the document name.

**Sampled reviews are short.** The team's remit is addressing, forwarding, and the
Internet layer generally; where a document does not touch those, the review says so and
stops.

**Watch for the review type in the header.** `intdir-telechat` and `intdir-early` are
both common, and a telechat review of a document already reviewed at Last Call is
conventionally a delta — what changed, whether the earlier comments landed — rather than
a fresh review.
